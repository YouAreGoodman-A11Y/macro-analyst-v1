# 宏观基调设定与预期备忘录 (P17)

**生成时间**：2026-06-02 09:38 CST
**关键新增数据**：美国5月ISM制造业PMI 54.0（2022年5月以来最高）

## 1. 宏观基本面底色 (低频定性)

### 美国账本
- **增长**：Q1 GDP 2.0%（环比折年率），非农+11.5万（超预期），ISM制造业PMI 54.0（+1.3pct创新高）→ **增长动能仍在扩张，但Q1 GDP从去年下半年的~3%放缓至2%，是温和减速而非崩塌**
- **通胀**：CPI 3.8%（前值3.3%加速）、CPI核心2.8%（前值2.6%）、PPI 6.0%爆表（前值4.3%）、ISM物价指数82.1（仍极高）→ **通胀顽固且有二次抬头迹象**
- **流动性**：Fed维持3.50-3.75%不变，10Y 4.475%仍在高位，长短端利差收窄中
- **就业**：失业率4.3%持平，初请20.5万健康，但ISM就业指数48.6仍处收缩（连续32个月）

### 中国账本
- **增长**：Q1 GDP 5.0%超预期（统计效应），4月工业利润+24.7%爆表（高技术+半导体驱动），但社零仅+0.2%几近停滞，固投同比-1.6%（房地产-13.7%拖累）→ **生产端强劲但消费端冰封，结构性撕裂加剧**
- **通胀**：CPI 1.2%（温和），PPI 2.8%（加速），油价输入性通胀推升PPI
- **流动性**：M2 8.6%（宽），但社融6207亿同比少增5392亿，4月新增人民币贷款罕见-100亿（住户贷款-4902亿）→ **宽货币+紧信用的极端背离**
- **PMI**：5月官方50.0（踩线），新出口订单48.6%（收缩），中小企业PMI 48.6%/48.5%（双收缩），高技术制造52.9%（扩张）

### 基调确立
- **美国**: **增长减速 + 通胀顽固 = 滞胀底色强化**（ISM PMI 54.0的扩张被物价82.1和就业48.6的撕裂对冲，实质是"滞胀的内部结构调整——制造业在涨但价格贵且招不到人"）
- **中国**: **生产复苏 + 消费冰封 + 信用枯竭 = 通缩压力与结构性复苏的极端分化**

## 2. 盘面标准答案清单 (高频特征预期)

如果上述"基本面底色"是正确的，高频市场理论上应出现以下特征：

### 【信用雷达预期 (HYG)】
- **预期**: HYG整体稳定或小幅走弱（滞胀环境下企业融资成本高企但非违约潮），信用利差不剧扩但也不收窄
- **理由**: ISM物价82.1压制利润空间，但PMI扩张54.0→企业收入仍在增长，违约概率不激进上升

### 【广度雷达预期 (RTY vs NDX)】
- **预期**: NDX继续跑赢RTY。滞胀环境下，资金偏好高利润率+定价权的科技巨头（NDX），而非能源/利率敏感的小盘股（RTY）
- **理由**: ISM物价82.1压缩中下游利润→大企业通过技术优势转嫁成本，小企业承压

### 【大宗雷达预期 (铜/金/油)】
- **预期**: **铜 > 油 > 金**。滞胀底色+AI工业需求支撑铜；油价受OPEC+主动增产+需求担忧双重压制；黄金实际利率高企下无避险买盘
- **理由**: ISM新订单56.8加速扩张→工业金属需求强；就业指数48.6收缩→消费驱动型需求（油）偏弱；物价指数仍高但环比下降→黄金无通胀溢价

### 【避险雷达预期 (VIX/美债)】
- **预期**: VIX低位（无惧滞胀，市场仍在消化PMI利好而非恐慌）；10Y收益率维持高位（4.4-4.6%）或受PMI超预期推动小幅上行
- **理由**: 54.0的PMI是增长利好，不会引发恐慌；物价82.1不会让收益率加速下行
