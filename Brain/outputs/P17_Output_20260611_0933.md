- 但核心CPI小幅回落 + 初请上升 → 暗藏"增长边际减速"种子
- 这不是经典衰退型滞胀，而是**增长见顶+通胀二次脉冲**的变体
- 6/17 FOMC会议是最大变量

## 2. 盘面标准答案清单 (高频特征预期)

如果上述"基本面底色"是正确的，那么在真实的高频市场中，**理论上必须**出现以下盘面特征：

### 🔍 【信用雷达预期 (HYG)】
- **预期**：HYG 稳定或微涨
- **逻辑**：ISM 54 + NFP 172K → 美国企业盈利有支撑，无衰退风险 → 信用风险溢价不上升
- **核心假设**：当前CPI是"通胀高但经济强"，不是"通胀高且衰退" → HYG不应崩跌

### 🔍 【广度雷达预期 (RTY vs NDX)】
- **预期**：**RTY 跑赢 NDX**（小盘 > 科技大盘）
- **逻辑**：ISM 54 = 美国本土制造业景气扩张 → 本土小盘企业直接受益
- **反面**：若NDX反而跑赢RTY，说明市场在交易"流动性宽松"而非"经济复苏"

### 🔍 【大宗雷达预期 (铜/金/油)】
- **预期**：**铜 > 油 > 金**（工业需求 > 能源供给 > 避险/利率敏感）
  - **铜**：ISM 54 直接利好工业金属 → 铜应表现最强
  - **油**：OPEC+/中东供给侧主导 ($91.79 = 地缘溢价), 与宏观需求脱钩 → 中间位置
  - **金**：CPI 4.2% + 利率居高不下 → 黄金是再通胀框架下最差的资产 → 应持续下跌

### 🔍 【避险雷达预期 (VIX/美债)】
- **VIX**：CPI 4.2%已落地, 核心CPI下行 → 恐慌情绪应均值回归, VIX应回落至18-19
- **10Y美债**：4.542%, CPI 4.2%定价合理 → 预计在4.4-4.7%区间震荡, 上行空间有限
- **USD/CNY**: 中间价6.813, 外储3.44万亿 → 汇率稳定, 无资本外逃风险
