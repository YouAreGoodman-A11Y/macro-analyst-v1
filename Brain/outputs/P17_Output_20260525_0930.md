# 宏观基调设定与预期备忘录 (P17)
**分析依据**：纯低频宏观数据（5/19抓取）
**生成时间**：2026-05-25 09:30 CST

## 1. 宏观基本面底色 (低频定性)

### 美国账本
- **增长**：Q1 GDP +2.0%（放缓但为正）；4月非农+11.5万超预期；ISM制造业52.7/服务业53.6——经济已从过热降温至**温和扩张区间**，但未衰退
- **通胀**：CPI 3.8%/Core CPI 2.8%/PPI 6.0%（全面超预期爆表）——通胀顽固且粘性极高，PPI向CPI传导压力加大
- **流动性**：Fed维持3.50-3.75%不变，10Y/2Y倒挂仍存在（4.558% vs 3.585%），长端利率因通胀预期持续上行——**紧信用环境延续**

**基调**：**滞胀（Stagflation）** ——经济增长放缓但仍为正 + 通胀顽固不下 + Fed按兵不动。这是典型的"有增长的滞胀"而非"衰退式滞胀"。

### 中国账本
- **增长**：Q1 GDP +5.0%面子数字；4月社零仅+0.2%（几近停滞）；固投转负（-1.6%）；房地产-13.7%——**内需极度疲软**
- **通胀**：CPI +1.2%（温和）、PPI +2.8%（输入性成本上涨）——表面温和但有PPI上行压力
- **流动性**：社融6207亿（同期少减5392亿）、新增人民币贷款罕见转负（-100亿）、住户贷款-4902亿——**宽货币(M2+8.6%) vs 紧信用(贷款为负)的极端背离**

**基调**：**通缩性衰退（Deflationary Recession）** ——信贷冰点+内需停滞+地产拖累。出口是唯一的亮点（4月出口+14.1%），但贸易摩擦风险持续施压。

### 基调确立
- **美国：滞胀（有增长的滞胀）**
- **中国：通缩性衰退**
- **全球宏观底色**：**中美双轨分化**——美国"死不降的通胀+死不了的就业"vs中国"宽货币但无人借钱"。

## 2. 盘面标准答案清单 (高频特征预期)

如果上述（滞胀+通缩）基调是正确的，高频市场理论上必须出现以下特征：

### 【信用雷达预期 (HYG)】
- **预期**：HYG温和承压但不崩（滞胀环境下信用利差窄幅走阔，但不是恐慌式爆雷）
- **逻辑**：美国就业韧性和企业盈利支撑信用质量，但高利率环境压制信用扩张

### 【广度雷达预期 (RTY vs NDX)】
- **预期**：**NDX持续跑赢RTY**（大科技霸权延续）
- **逻辑**：滞胀环境中，大科技（高利润率+AI叙事+低资本密度）天然优于小盘（高利率负债+低定价权）

### 【大宗雷达预期 (铜/油/金)】
- **通胀上行预期 = 油强铜弱**（成本推动型通胀利好上游）
- **但需要注意**：油有供给侧独立冲击的可能（地缘风险释放），铜的价格=中国需求+美元定价
- **黄金**：滞胀教科书说应该强，但实际利率高位压制令黄金是"假利好"，预期偏弱

### 【避险雷达预期 (VIX/美债)】
- **预期**：VIX在15-20区间震荡（有序滞胀，非恐慌）
- **10Y**：4.5%+运行，但不会失控飙升（Fed观望但不会加息，市场price-in通胀但不过度恐慌）
- **DXY**：99-100区间震荡偏强（通胀因素支撑美元）
