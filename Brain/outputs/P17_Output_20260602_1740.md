# 宏观基调设定与预期备忘录 (P17)
**分析依据**：纯低频宏观数据
**生成时间**：2026-06-02 17:40 CST
**关键数据**：美国5月ISM制造业PMI 54.0（2022年5月以来最高）, 中国5月官方制造业PMI 50.0

## 1. 宏观基本面底色 (低频定性)

### 美国账本
- **增长**：Q1 GDP 2.0%（环比折年率），ISM制造业PMI 54.0（+1.3pct创新高），新订单56.8（+2.7pct）→ **制造业扩张加速，增长动能从"温和减速"修正为"再次提速"**
- **通胀**：CPI 3.8%加速（前值3.3%），PPI 6.0%爆表（前值4.3%），ISM物价指数82.1（仍极高）→ **通胀顽固且有二次抬头迹象**
- **流动性**：Fed维持3.50-3.75%不变，10Y 4.475%高位，长短端利差收窄
- **就业**：失业率4.3%持平，ISM就业指数48.6（连续32个月收缩）→ **制造业扩张未能转化为劳动力增量需求**

### 中国账本
- **增长**：Q1 GDP 5.0%（超预期），4月工业利润+24.7%（高技术+半导体驱动），但社零仅+0.2%（几近停滞），固投同比-1.6%（房地产-13.7%拖累）→ **生产端强劲但消费端冰封**
- **通胀**：CPI 1.2%（温和），PPI 2.8%（加速，油价输入性），中国10Y 1.70%持续下行→ **通缩压力而非通胀**
- **流动性**：M2 8.6%（宽），但社融6207亿同比少增5392亿，4月新增人民币贷款罕见-100亿（住户贷款-4902亿），中国10Y 1.70%反映资产荒→ **宽货币+紧信用的极端背离**
- **PMI**：5月官方50.0（踩线），新出口订单48.6%（收缩），中小企业48.6%/48.5%（双收缩），高技术制造52.9%（扩张）→ **结构性撕裂在PMI层面确认**

### 基调确立
- **美国**: **增长再加速 + 通胀顽固 = 滞胀底色延续但内部分化扩大**（ISM PMI 54.0说明制造业确实在扩张，但物价82.1和就业48.6意味着这个扩张是"高成本、低就业增长"的滞胀特征）
- **中国**: **生产强复苏 + 消费冰封 + 信用枯竭 + PMI踩线 = 通缩压力与结构性复苏的极端分化**（高技术制造仍在扩张，但中小企业、消费端都在收缩，总PMI仅50.0说明增长极窄）

## 2. 盘面标准答案清单 (高频特征预期)

如果上述"基本面底色"是正确的，那么高频市场**理论上必须**出现以下盘面特征：

* **【信用雷达预期 (HYG)】**：预期HYG稳定或小幅走弱。逻辑：ISM物价82.1压缩企业利润空间但PMI 54.0保障企业收入，滞胀环境下的信用市场是"稳定但不扩张"。
* **【广度雷达预期 (RTY vs NDX)】**：预期NDX跑赢RTY。逻辑：滞胀环境下利润率高的科技巨头通过技术优势转嫁成本压力，而利率敏感+成本敏感的小盘股承压。
* **【大宗雷达预期 (铜/金/油)】**：预期**铜 > 油 > 金**。逻辑：ISM新订单56.8→工业铜需求强；ISM就业48.6→消费驱动型需求（油）偏弱；实际利率高企→黄金无避险买盘。
* **【避险雷达预期 (VIX/美债)】**：预期VIX低位稳定（无恐慌），10Y收益率高位（滞胀不支持利率大幅下行）。
