## 1. 宏观基本面底色 (低频定性)

### 美国账本
- **增长**：**分化的两速经济**。ISM制造业54.0连续三个月扩张（工业端健康），零售4.9%显示消费惯性仍在，NFP+17.2万算健康。但亮点已出现裂缝：**新屋开工暴跌15.4%**至2020年5月最低，密歇根消费者信心46.6连续三个月下滑，初请失业金22.9万升至三个月高位。实体经济正在从"韧性扩张"切换至"减速但未崩盘"。
- **通胀**：**二次通胀正式确认**。CPI 4.2%创三年新高，PPI 6.5%为2022年11月以来最大涨幅。核心CPI 2.9%有粘性但环比0.2%略好于预期。能源（汽油+10.7%）是最主要的推手，但服务通胀也在扩散。**PPI向CPI传导压力持续加大**。
- **流动性**：利率3.50-3.75%维持不变（FOMC今晚决议）。市场预期不加息，但CPI 4.2% + PPI 6.5%的组合拳给FOMC带来显著鹰派压力。点阵图是否上修是核心变量。
- **基调判定**：**【滞胀边缘 — 减速扩张 + 二次通胀】** 不是典型的"衰退前夜"也不是"强劲金发女郎"。实体经济在减速但ISM仍在扩张区，通胀顽固但核心环比有缓解。"减速+高通胀"的组合是最让美联储头疼的。

### 中国账本
- **增长**：**极端结构撕裂**。工业增加值4.5%超预期扩张（生产端强势），但社零-0.6%年内首次**转负**（消费端实质性萎缩），固投-4.1%大幅恶化（投资端崩盘）。三个核心引擎：**生产↑ / 消费↓ / 投资↓↓**。这种剪刀差不可持续。
- **通胀**：**通缩+成本推动的混合体**。CPI 1.2%温和（实际上已徘徊在通缩边缘），PPI 3.9%攀升造成PPI-CPI剪刀差扩大。中下游制造业毛利率被上游成本推高+下游消费疲软双向积压。
- **流动性**：**总量宽松 + 传导受阻**。社融2.03万亿超预期、M2 8.6%持平、信用利差40.43bp（宽松区间）、DR007 1.46%（宽松）。钱印了但大部分堵在银行间和国债市场，没有流入消费和投资。两融余额2.889万亿显示股市内部杠杆稳定，但成交量仅0.97x均量。
- **基调判定**：**【通缩撕裂 — 生产强/消费崩/投资垮】**
  - 最准确的定性：生产端的"假繁荣"掩盖不了消费和投资端的实质性衰退
  - 5月社零转负是里程碑事件——这是中国经济自开放以来首次在非疫情月份出现零售同比负增长
  - 人民币汇率稳定（USD/CNY 6.755）说明没有资本外逃恐慌，但内需问题纯靠货币宽松解决不了

### 重大外部冲击

## 2. 盘面标准答案清单 (高频特征预期)

### 【信用雷达预期 (HYG)】
**方向：稳定偏强 → 预期HYG韧性延续**
基于美国ISM 54 + 零售4.9% + 社融超预期（中国端信用也不差）= 企业基本面尚可支持信用债定价。但PPI 6.5%和CPI 4.2%的成本压力最终会传递到企业利润端，如果FOMC后利率环境收紧，HYG可能在1-2周后出现压力。
- **如果正确**：HYG四周期(1d/5d/20d/60d)应全线保持在0%附近或正值
- **如果证伪**：HYG 5d转负或1d单日崩跌>1.5%，则是"信用端真问题"启动

### 【广度雷达预期 (RTY vs NDX)】
**方向：预期 RTY 跑赢 NDX（顺周期广度扩张持续）**
ISM 54 + 美国工业端扩张 → 顺周期逻辑支撑小盘股领先。减税/监管放松的"动物精神"逻辑持续支撑美国中小企业的估值重定价。NDX在CPI 4.2%和高利率环境下面临估值压制，且NDX 60d +25.4%已非常极致。
- **如果正确**：RTY 20d/60d继续保持>NDX，且5d方向一致
- **如果证伪**：NDX重新大幅跑赢RTY（>3pp），说明市场重回流动性追逐科技龙头的避险模式

### 【大宗雷达预期 (铜/金/油)】
**方向：铜 ≫ 油 > 金（再通胀逻辑下铜最强，油中性偏弱，金最弱）**
- **铜 (超配)**：ISM 54 + 工业用电化/AI基建需求 = 铜仍是本轮再通胀最强锚。60d已+19.86%验证了季线信仰。
- **油 (标配/不抄底)**：PPI 6.5%中能源是最大推手，但OPEC+增产预期 + 中国消费崩塌(-0.6%社零)压制需求侧。供给叙事主导，20d -30.58%说明市场在定价全球需求下降。
- **金 (低配)**：CPI 4.2%、核心CPI 2.9% = 实际利率维持高位 / 不降息 = 黄金持有成本高。60d -1.42%季线仍在下行通道。
- **铜金比扩张是本轮最核心的再通胀验证哨**：预期铜60d继续>金60d，裂差>10pp。
