# 宏观基调设定与预期备忘录 (P17)
**分析依据**: 纯低频宏观数据（含今日新增工业利润数据）

## 1. 宏观基本面底色 (低频定性)
* **美国账本**: 滞胀 — GDP 2.0%扩张、非农+11.5万韧性，但CPI 3.8%+PPI 6%全面爆表。Fed按兵不动，控通胀优先。
* **中国账本**: 结构性撕裂 — 工业利润+24.7%创近两年新高（电子/有色爆发），但社零+0.2%停滞、新贷-100亿冰点、固投-1.6%（地产-13.7%）。
* **基调确立**: 🇺🇸美国: 滞胀（通胀失控型） / 🇨🇳中国: 结构性撕裂

## 2. 盘面标准答案清单 (高频特征预期)
如果上述"基本面底色"是正确的，那么：
* **【信用雷达预期 (HYG)】**：滞胀下信用利差应温和走阔，HYG平盘至微跌
* **【广度雷达预期 (RTY vs NDX)】**：NDX(大科技)应持续跑赢RTY — 出口+高科技爆发支撑大科技霸权
* **【大宗雷达预期 (铜/金/油)】**：铜最强势（中国工业需求），油维持高位但承压（OPEC+供给vs需求矛盾），黄金最弱（和平红利消灭避险溢价）
* **【避险雷达预期 (VIX/美债)】**：10Y>4.5%高位运行，VIX 17-19非恐慌区间
