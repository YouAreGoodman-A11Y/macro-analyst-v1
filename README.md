# 🌐 宏观分析师系统 (Macro Analyst V4.0)

[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![LLM Agent](https://img.shields.io/badge/Agent-Autonomous-orange)](#)
[![Status](https://img.shields.io/badge/Status-Production_Ready-success)](#)

这是一个全自动的**宏观量化与逻辑推演智能体 (AI Macro Analyst)**。
系统从最初的“人工闹钟”迭代为当前的“全球宏观与中国本土流动性双轨交叉验证架构”（V4.0），实现了从数据抓取、逻辑推演到实盘盘口交叉套利的端到端无人值守闭环。

---

## 📌 系统演进背景：从“刻舟求剑”到“中美双轨双逻辑”

在 V3 及之前的时期，系统存在以下痛点：
1. **中美逻辑混用**：用美股的流动性/衰退逻辑去硬套 A 股的政策市、资金市，导致在面对“国家队护盘”或“游资微盘炒作”时产生严重幻觉和误判。
2. **存量估算反爬封锁**：各大 API 下架社融存量数据，导致中国信用周期判定经常取不到真实数据。

基于此，**V4.0 架构**对系统底层进行了根本性重构：
> **拆分中外：全球宏观底色看美元和大宗，中国本土盘面看拆借利率、两融和风格价差。两者裂痕即为套利空间。**

---

## 🏗️ 核心架构设计：四维数据引擎与 P 系列工作流

### 1. 数据引擎层 (Eyes)
彻底解耦低频基本面、全球高频和中国内盘流动性，确立“三轨并行”：
*   **低频基本面底座**：读取重磅官方数据（非农、CPI、GDP等）。
*   **外盘与大宗动量 (V5 引擎)**：`fetch_high_freq_with_changes_v5.py`，抓取美债、外汇、铜金比、RTY/NDX等全球核心资产的多周期动量。
*   **中国 4D 本土流动性 (4D 引擎)**：`fetch_cn_macro_4d.py`，通过独创的“增量递推法”精准还原社融存量，同时拉取 DR007、Shibor同业拆借、两融变动（1d/20d）以及 A 股三大场内风格价差（微盘vs大盘、红利vs大盘）。

### 2. 分析推理层 (Brain) - 核心四道防线
大模型提示词（Prompt）严格切分为四大工序，各司其职：
*   **P17 (基本面法官)**：只看低频数据。严禁看盘，只输出跨周期的**宏观重力预期假说**。
*   **P18 (全球高频助教)**：只看 V5 引擎数据。拿着高频盘口去批改 P17 的答卷，用铜金比和汇率验证全球周期。
*   **P20 (A股真实水位吹哨人)**：**新增！** 只看中国 4D 引擎数据。独立定性 A 股是“水牛”、“缩量防御”还是“信用扩张”。
*   **P19 (裂痕套利总司令)**：汇总 P17、P18、P20，寻找中美宏观周期的错位与微观盘口的裂痕，给出具体的 A 股结构配置指令。

### 3. 风控调度层 (Monitor)
*   零干预闭环管家与全自动高频异常监控。
*   **量化输出接口**：P19 将最终裁决直接输出为供 RL（强化学习）量化引擎读取的 `rl_parameters` JSON 指令，控制仓位（`cash_ratio_min`）与股票池切换。

## 📊 产出物标准与状态机规范 (State Machine)

### 1. 最终研报输出规范 (P19)
每次流水线执行完毕，必须产出《宏观大盘研判与实战策略报告》，涵盖四大核心：
*   **中美宏观与现实裂痕**：基本面与高频资金面的底层冲突。
*   **大类资产与 A 股结构配置**：基于动量的超配、标配、低配红绿灯。
*   **动态风控剧本**：主线延续、强制缝合、黑天鹅三种剧本兵棋推演。
*   **RL 量化执行指令**：JSON 格式的机器操作协议。

### 2. 全局状态机分流 (Source of Truth)
系统现在将状态机一分为二，作为策略端的双重视角：
*   **全球宏观状态机** (`宏观环境_状态机.md`)：由 P18 强制覆写。
*   **中国盘面状态机** (`中国盘面_状态机.md`)：由 P20 强制覆写。
